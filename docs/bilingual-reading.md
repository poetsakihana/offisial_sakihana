# 日本語と英語の朗読

公式恋愛詩人 咲華（さきはな）の公開サイトに組み込んだ、日英の読み上げ機能です。

公開先: https://sakihana-poetry.maroonshell4.chatgpt.site/

このGitHubリポジトリでは、今回追加した朗読モジュールと参考英訳を管理します。サイト全体の画像・音源・管理機能の複製や、GitHub Pagesへの移転は含みません。

## 利用方法

1. 作品を開き、「英訳・英語の朗読」を選ぶ。
2. 「日本語で聴く」で原文を再生する。
3. 「英訳を表示」で訳文を準備し、「英語で聴く / Listen in English」で再生する。
4. 停止・一時停止・再開・速度変更は既存の朗読操作を使う。英語の声は専用の選択欄で選ぶ。

全集の詩2,134篇、本人の既存名言521項目、AI新作名言600作の既存プレーヤーに同じモジュールを組み込んでいます。写真・あとがきは詩の連続朗読対象に含めません。

## 実装

- `public/assets/tts.js`: 日本語・英語の発話言語と音声を一致させる再生エンジン。言語切り替え時も古い発話の完了・エラーを無視する。
- `public/assets/bilingual.js`: 作品選択、英訳表示、音声選択、取得の中止、原文と英訳の表示、翻訳キャッシュ。
- `public/assets/bilingual.css`: 既存の配色を引き継いだ画面。狭い画面では操作ボタンを縦に配置する。
- `content/english-translations.json`: 代表作9篇のAIによる参考英訳と、それに対応する日本語原文。
- `public/assets/english-translations.json`: サイトが読み込む公開用コピー。

ホスト画面ではCSSと `tts.js`、`bilingual.js` の順に読み込み、カタログ取得後に既存プレーヤーを渡します。`poems` は公開済みの作品だけにします。

```javascript
PoetryBilingual.mount({
  host: document.querySelector('.audio-panel'),
  speaker, // 既存の PoetrySpeaker インスタンス
  poems: catalog.filter(poem => poem.ttsBody && !poem.nonPoem),
  initialId: 'saki-2135'
});
```

英文は `speaker.start([{...poem, ttsBody: translatedText, lang: 'en-US', voiceURI}])` で読み上げます。日本語の作品は従来どおり言語指定を省略できます。保存済みの日本語音声が英文を読むことや、その逆を防ぎます。

`scripts/build.py` は全作品の共通ヘッダーに新しいCSS・JavaScriptを追加し、個別ページに英訳へのリンクを出力します。参考英訳の日本語が現在のカタログの原文と一致することもビルド時に確認します。詩・名言それぞれのカタログ取得後に、既存の再生エンジンを共有して画面を接続しています。

## 翻訳と音声の条件

参考訳がある9篇は外部翻訳通信なしで表示できます。ほかの作品は、利用者が「英訳を表示」を押したときだけMyMemoryの公開翻訳APIへ本文を送ります。利用者のメールアドレス・認証情報・管理データは渡しません。翻訳結果は参考訳であり、咲華本人による公認英訳を意味しません。

APIの上限は1リクエスト500バイトです。480 UTF-8バイト以下に分割し、Unicode文字を途中で切りません。無認証利用のサービス上限は1日5,000文字です。上限・通信エラー・タイムアウトを表示し、失敗した途中の訳は保存しません。完了した自動翻訳だけを最大60作品、このブラウザに保存します。原文が変わった場合は古い訳を再利用しません。

外部から返された訳文は文字列として画面に表示します。翻訳後に音声を自動再生せず、別の再生ボタン操作で開始します。端末の日本語・英語の合成音声が必要です。本人の録音音声ではありません。画面ロック・背景再生の可否はOSとブラウザに依存します。

仕様: https://mymemory.translated.net/doc/spec.php

利用上限: https://mymemory.translated.net/doc/usagelimits.php
